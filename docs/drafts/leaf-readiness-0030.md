# Проверка готовности листа 0030: графики и история

**Готовность к реализации не установлена.** Это авторский разбор черновика
[0030](GITVIEW-SPEC-0030.yaml), не independent review и не проверка API.

| Утверждение | Необходимая основа | Что не следует из неё само собой |
| --- | --- | --- |
| Объект закрыт сейчас | Достоверное наблюдение текущего состояния. | Время закрытия и количество прошлых закрытий. |
| Issue закрылся в заданный день | Подтверждённое время конкретного события внутри границ дня. | Полная история событий дня или успешное завершение работы. |
| Два closure events за день | Достаточная история событий и различимость двух событий в заданном scope. | Два разных Issue или две успешно выполненные задачи. |
| Один Issue с closure за день | Установленная identity Issue и хотя бы одно подходящее событие; для полного числа — достаточное покрытие всех таких объектов. | Количество событий этого Issue или полный список событий. |
| Все открытые объекты в прошлом на момент T | Полное наблюдение соответствующего scope на T либо надёжное восстановление такого состояния. | События между T и последующим снимком. |
| Project series за прошлый период | Явно выбранный состав участников для этого утверждения и данные по нему. | Что нынешние участники входили в Project в момент событий. |

Наблюдение в среду события, произошедшего в понедельник, не переносит событие
на среду. Локальный день и границы bucket определяются контекстом периода;
точная политика исторических time zones остаётся открытой. Разрешение причины
закрытия относится к конкретному событию: известная сейчас причина не обязана
описывать прошлое закрытие после reopen.

Родители и зависимости задают отдельные ограничения на доступ, identity,
покрытие, текущее состояние и Today. Ещё не определены доступность event
history в источнике, точный набор поддерживаемых series, правила membership во
времени, формула burn-down и источники достаточности coverage. Сценарии в YAML
— ожидаемые результаты; ни приложение, ни источник по ним не проверялись.
