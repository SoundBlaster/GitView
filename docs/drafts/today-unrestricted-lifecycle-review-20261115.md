# Today: отсутствие lifecycle-фильтра и неизвестный статус

При сверке [0027](GITVIEW-SPEC-0027.yaml), [0092](GITVIEW-SPEC-0092.yaml)
и [0110](GITVIEW-SPEC-0110.yaml) обнаружилась неоднозначность: default показывал
все состояния выбранными, но общая фраза об unknown lifecycle могла заставить
считать сам default неизвестным фильтром. Это противоречило включению объекта
по независимо подтверждённому событию за Today.

Уточнённый candidate различает **нет ограничения** и **выбранное подмножество**:
при отсутствии lifecycle restriction подтверждённое событие может включить
объект с неизвестным текущим статусом; сам статус остаётся unknown. При явном
фильтре только open тот же объект остаётся uncertain до установления текущего
состояния. Повторный выбор всех поддерживаемых статусов возвращает отсутствие
ограничения, а не скрыто исключает неизвестные или будущие source values.
Явно пустой набор по-прежнему исключает соответствующий тип, не доказывая
пустоту GitHub.

Повторно исполнена ранее существовавшая [конечная модель](evidence/today-selection-access-model.py):
34 992 сочетания и авторский пример 100 → 95 merged → 5 после фильтра прошли.
Два дополнительно проверенных абстрактных входа с истинным Today event и
unknown lifecycle дали `true` без ограничения и `unknown` с ограничением.
Модель исходит из авторами выбранной независимости входов; она не проверяет
перевод реальных source facts, UI, iOS, поведение приложения или полноту
населения. JSON прогона сохранён на TB5 в
`/Volumes/TB5/Developer/Builds/GitHub/GitView-a40d73ccf162f8d8/gitview-unrestricted-lifecycle-model.json`.

Отдельно SpecGraph проверил изменённые 0027, 0092 и 0110 в выбранной draft.11
композиции; это structural advisory, не semantic approval и не выполнение
product scenarios. Source-specific completeness и транзитивные prerequisites
листа остаются открытыми.
