# Preview первой версии: содержание и доступность

Сверка 0015 → 0031 → 0050 → 0093 с выбранными полями PR и Issue.
Long-press static preview — требование первой версии; последующее скольжение
одного rich preview между клетками здесь не объявляется реализованным.

| Объект | Приоритет при доступном evidence | Что остаётся отдельным |
| --- | --- | --- |
| Project | Разрешённое имя, охват участников, доступные work и attention signals. | Project — локальный объект; ссылка на один Repository не становится ссылкой на весь Project. |
| Repository | Разрешённое имя и source context, доступные сводки PR/Issue и freshness. | Участие в нескольких Projects не меняет identity; неполное покрытие не является пустым репозиторием. |
| PR | Название, номер и Repository, lifecycle/draft, затем доступные CI, review, треды и счётчики изменений. | CI, review и threads независимы; diff, содержимое тредов и отдельные checks не обязательны в preview. |
| Issue | Название, номер и Repository, lifecycle/reason, затем доступные assignees, discussion/sub-issue counts и blockers. | Закрытие не равно выполнению; private blocker нельзя раскрывать через derived count. |

Сначала сохраняется способность идентифицировать выбранный объект и открыть его;
дополнительные детали доступны при наличии места либо через допустимый
overview/accessibility путь. В отсутствие факта нельзя подставлять ноль,
успех или сгенерированный текст. Короткий source excerpt сохраняет авторство и
контекст; отсутствие excerpt не доказывает пустой body.

Previously permitted cached content может открываться без ожидания сети.
Поздние ответы применяются только к правильному объекту и разрешённому scope;
после denial они не восстанавливают private доступ сами по себе. Открытие
source и sharing — необязательные действия, зависящие от допустимой ссылки;
после передачи системе невозможно гарантировать отзыв переданных данных.

Порядок, адаптация Dynamic Type, конкретные нативные компоненты и gestures —
рабочее предложение, не проверенное на устройстве. Выбор состава полей не
доказывает, что каждый из них доступен в конкретном GitHub grant.
