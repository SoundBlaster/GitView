# Проверка готовности листа 0028: CI и review

**Готовность к реализации не установлена.** Это авторский разбор candidate
[0028](GITVIEW-SPEC-0028.yaml), не проверка GitHub API и не independent review.

| Наблюдение | Допустимый вывод | Чего оно не доказывает |
| --- | --- | --- |
| Подтверждённая failed check связана с наблюдаемой revision; остальные checks загружены частично | В этом наблюдении есть failed check, coverage неполное. | Полное число failed checks, текущий статус после последующих изменений, mergeability. |
| В частичной коллекции не встретилась failed check | Нет подтверждённого результата об отсутствии failures. | Zero failed checks, успешный CI. |
| Полная и корректно классифицированная коллекция текущих checks пуста | Известный zero checks в этом scope и времени. | Что PR готов к merge. |
| Есть один unresolved thread в частичной коллекции | В этом наблюдении есть unresolved thread; общий count может быть неизвестен. | Общий review assessment и полное число threads. |
| Нет unresolved threads в полной коллекции, но review request for changes | Независимые факты: zero unresolved и changes requested. | Approval, отсутствие проблем или готовность к merge. |
| Failure относится к предыдущей revision, текущая revision другая | Историческое наблюдение о прошлой revision с его временем. | Failure или success текущей revision. |

Для Project положительный наблюдённый PR может войти в частичное множество
затронутых PR один раз; неизвестный PR не становится отрицательным результатом.
Эта сводка не обязательно является нижней границей текущего состояния при
устаревших наблюдениях и не устанавливает точного общего количества.

Перед реализацией необходимо определить source mapping check identity,
retry-equivalence, revision association, special conclusions и thread
resolution, а также доказательство полноты соответствующих scopes. Требуются
предки и зависимости 0011, 0026, 0044, 0046 и согласованные UI/accessibility
правила. Эти таблица и сценарии — ожидаемая интерпретация; приложение,
GitHub и устройство не проверялись.
