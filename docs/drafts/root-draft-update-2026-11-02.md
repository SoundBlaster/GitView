## Что остаётся открытым

Activity вынесена из списка сущностей в гипотезу о действиях; отдельная сущность
пока не вводится (`excerpt-28-reply`). Технические bindings GitView, User и
GitHubRepository отсутствуют; классы ради прохождения проверки не создавались.
Полные определения PR/Issue, типы свойств, unknown, source mappings и действия
требуют дальнейшей работы.

Правило Repository D «проверки и review пройдены» не принято автоматически:
согласованный Project B4 сохраняет условие отдельного выбора этого правила.
Периоды по умолчанию и остальные блоки repository-summary proposal остаются
предложениями. Точные CI-статусы, актуальная попытка/ревизия, freshness,
readiness, thresholds и исторические метрики не определены окончательно.

Полный документ уровней масштаба и содержимое прототипов не стали требованиями
целиком. Активация будущего sliding preview через long press остаётся гипотезой;
календарь, hover, точные переходы/возврат, доступность и глубина внутри PR требуют
отдельного решения или спецификации. Механизмы доступа, синхронизации, sharing,
deployment target и интеграции библиотек также открыты.
