# GitView: интерактивный пример Peek and Pop

Статус: UX-прототип для обсуждения, подготовленный по запросу пользователя
«Хорошо, давай.» (`conversation:gitview/excerpt-45-reply`) в ответ на предложение
показать прямо в чате переходы «сетка → preview → объект».
Это не реализация iOS-приложения, не canonical specification и не утверждение
пользователем показанных размеров или содержания карточек.

Исходник предназначен для показа в беседе и находится в её постоянном каталоге:
`/Users/egor/.codex/visualizations/2026/10/26/01a179ec-2ed5-7923-bdb1-b24739653482/gitview-peek-pop.html`.
Это локальное местонахождение макета, не URL публикации; приложение в репозитории
GitView по-прежнему не реализовано. HTML не устанавливался как сайт и не
копировался в приложение. Требование полного Git-хранения истории относится
к SpecDraft; его данные сохранены с этим документом.

## Показанный сценарий

По последующему запросу пользователя (`excerpt-48`) сохранена независимая
[HTML/CSS/JS-версия](../../prototypes/peek-pop/index.html) с локальными
ресурсами. [Каталог и запуск](../../prototypes/README.md). Исходный inline-пример
сохранён отдельно; синхронизация дальнейших правок не автоматическая.

- Сетка из четырёх PR и двух Issue в контексте демонстрационного репозитория.
- Tap открывает обзор; long press около 500 ms или кнопка с глазом — preview.
- Preview содержит заголовок, состояние, метрики и фрагмент Motivation.
- Действие «Открыть» переводит в тот же объект; «Закрыть», фон и Escape
  возвращают в сетку. Возврат из объекта сохраняет фильтр.
- Для PR показаны review, CI 3/4/8/15, треды и размер изменений. Для Issue —
  комментарии, участники, sub-issues и blockers.
- В обзоре объекта раскрыты согласованные разделы описания. Все числа,
  тексты описаний и статусы вымышлены; названия не являются данными из GitHub.
- Контролы «Сетка / Предпросмотр / Объект» находятся вне изображённого приложения
  и служат для просмотра трёх состояний. Это не предложение добавить их в GitView.
- Host design controls позволяют сравнить детализацию сетки и наличие
  Motivation в preview. Это параметры обсуждения, не новые настройки продукта.

Скользящий preview между ячейками не реализован в этом примере: он остаётся
следующим сценарием из [черновика взаимодействий](ux-preview-interactions.md).
Макет не доказывает поведение нативного context menu, свойства Liquid Glass,
поддержку SF Symbols или работу жеста на физическом iPhone.

## Проверка

В browser preview проверены кнопка предпросмотра, long press мышью,
переход preview → объект, возврат и фильтр Issue. Проверены preview всех шести
объектов на узком экране; при ширине браузера 320 px и внутренней ширине 288 px
горизонтального overflow не обнаружено. Просмотрены светлая сетка и тёмный
preview; Reduce Motion включался при узкой проверке. Это не полная проверка
доступности, native-device test или проверка внешнего источника.

Проверка исходника: HTML fragment без внешних API-запросов, буквальная разметка,
размер меньше 1 MB. Прототип не отправляет комментарии или другие изменения
в GitHub. Состояние выбора сохраняется только через доступный host state API.

Следующее обсуждение: размер preview, полезность показанных метрик и читаемость
Motivation. Далее — отдельный сценарий long press → скольжение между карточками.
