## Что подтверждено и чего не следует заключать

Проверены восемь evidence-файлов и 26 GraphQL-примеров: hash документов, hash каждой операции с указанной в отчёте нормализацией, имена и статическая проверка на сохранённом GitHub public schema snapshot. Схема загружена с `assume_valid`; сеть, авторизация, реальные permissions, семантика результатов и source coverage не проверялись. Расчёт hash в исходном Today-отчёте использовал `strip`, остальные — текст блока с конечным переводом строки; это теперь указано в каждом отчёте. Совпадение hash не является проверкой предметного смысла.

Сценарии и связи графа не заменяют конкретные operation-to-field permissions, последующую проверку живого источника или нативного поведения. Среди остающихся upstream-границ — окончательный auth/registration profile, согласованные public Swift interfaces и FSD assembly, физическое хранение и recovery, а также UX и accessibility на устройстве. Исторические значения требуют отдельных evidence и retention; предложенный источник поля не доказывает исторический snapshot. Численные API budgets и реализация отложены.

Следующий содержательный проход — оценить, какие согласованные поля и правила ещё не имеют достаточно конкретного интерфейса, а каждую группу сохранять с её собственными access и coverage. После этого повторить оценку readiness по маршруту, а не подсчитывать количество синтаксически проверенных запросов как меру готовности продукта.
