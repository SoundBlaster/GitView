# GitView: сквозные сценарии и пределы свидетельств

Рабочая карта [0043](GITVIEW-SPEC-0043.yaml) связывает намерение с границами
ветвей. Все перечисленные результаты — **ожидаемые**, не выполненные тесты и
не подтверждение готовности приложения или графа.

| Сценарий | Основные ветви | Существенный проверяемый результат | Следующее свидетельство |
| --- | --- | --- | --- |
| Два Repository в разных организациях | 0022, 0025, 0045 | Раздельные default Projects с сохранением source identity. | Хранилище и авторизованный discovery, когда реализация разрешена. |
| Один Repository в двух Projects | 0025, 0029, 0046 | Участие в обоих Projects, один вклад в уникальный portfolio. | Поведенческие tests с fixtures и отдельное integration evidence. |
| 95 из 100 PR влиты сегодня | 0007, 0027, 0049 | Карточки остаются без явного фильтра; источник и покрытие не теряются. | Сценарий selection и native interaction с достаточными source fixtures. |
| Прерванный выбор после частичного сохранения | 0045, 0052 | Сохранённый Project восстанавливается, неизвестный исход не превращается в повторное создание. | Проверка реального durable storage, process termination и конкурентных попыток. |
| Refresh частично объединён и отложен | 0044, 0048 | PR success не подтверждает Issue coverage; переход на другой экран не меняет scope запроса. | Контролируемые scheduler/network doubles и отдельная проверка iOS/GitHub. |
| Частичный failed-CI сигнал | 0028, 0046, 0047 | Известная проблема доступна; неизвестные PR не считаются здоровыми. | Контрактные fixtures и фактическое отображение uncertainty. |
| Отказ доступа при preview и sharing | 0031–0033, 0036–0037 | Private данные скрываются визуально и для assistive input; ограниченная ссылка не передаётся после denial. | Проверка access signals, native preview и share handoff. |
| Историческое закрытие с reopen | 0029–0030 | Условие события сохраняется при переходе к Issue с текущим open state. | Подтверждённая event history и проверка фильтра соответствующего периода. |
| Обязательный формат и внешний Issue | 0010, 0034, 0051, 0054 | Процесс проверяет новые объекты в выбранных участниках; GitView не скрывает внешний unstructured Issue. | Решение об участниках и enforcement, реальные проверки supported creation paths. |

Единичный end-to-end test не заменяет независимые проверки policy, storage,
source adapter и platform; тест с doubles не подтверждает реальный GitHub.
Сценарии не исчерпывают все комбинации, а перечисленные будущие проверки не
являются разрешением начинать implementation до готовности графа.
