# Сводки и метрики: независимая сверка

На `c0bc8b1` независимый read-only reviewer сопоставил 0005, 0012, 0013 и
0047 с согласованной сводкой Project. Прямых противоречий по Repository в
нескольких Projects, уникальным portfolio totals, условной ready-выборке и
неполным данным не обнаружено.

Остаются продуктовые вопросы:

1. Историческая основа состава: график за прошлый месяц может использовать
   нынешний состав Project либо состав на каждую дату. Это даёт разные результаты
   при добавлении или удалении Repository; вопрос передан владельцу.
2. Какие сведения о полноте можно показывать при скрытом Repository: например,
   `4/5` может раскрыть существование ограниченного участника. Зависит от
   ещё не выбранной disclosure policy.
3. Единица исторических закрытий: Issue, дважды закрытая за период, может
   считаться одним объектом или двумя событиями. 0013 пока не выбирает единицу.
4. Проектное предложение называет полезными число объектов и число затронутых
   Repositories; 0047 допускает их раздельную доступность, не фиксируя, где и
   всегда ли оба значения обязательны.

Это проверка указанных четырёх узлов, не всего графа и не реализации.

Позднее владелец выбрал пересчёт исторических графиков по нынешнему составу
Project; решение и точная цитата записаны в SpecDraft revision
`a55f271ca16f4283bfaf67095616ee7a`. Это закрывает пункт 1 для графиков,
но не выбирает автоматически основу всех исторических счётчиков и выборок.
Ограниченная независимая сверка обновлённых 0013 и 0047 прошла для SHA-256
`c1abfca6f5ec7134b53fc94dfa2441f3f8ac7407c45b3be098cea007f8e27af3` и
`113804876c2ce5c99b1f462ccf71b6c02e6ea75736d8efd4d3cc7ed90f14d14c`.
