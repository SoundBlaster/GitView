# Проверка готовности листа 0032: доступность основных задач

**Готовность к реализации не установлена.** Авторский анализ использует
локальный skill [ios-accessibility](/Users/egor/.codex/skills/ios-accessibility/SKILL.md);
он не подтверждает поведение GitView на устройстве или поддержку конкретной
assistive technology.

| Задача | Требование к доступному пути | Связанная ветвь |
| --- | --- | --- |
| Подключить источник, выбрать Repository, восстановить ошибку | Действия и ошибка доступны без жеста, цвета и исчезающего уведомления. | 0022, 0036, 0045 |
| Найти Project и открыть PR/Issue | Идентифицировать доступный объект и контекст, различить одноимённые номера в разных репозиториях. | 0047, 0042 |
| Изменить масштаб и фильтр | Есть путь без pinch; scope, фильтр и identity не меняются из-за плотности. | 0035, 0027 |
| Закрыть preview или вернуться | Вернуть фокус на допустимый исходный объект или понятный fallback без подмены identity. | 0031, 0024 |
| Обнаружить ошибку обновления | Ошибка и время последнего успешного наблюдения остаются доступными после исчезновения временного сообщения. | 0023, 0044 |
| Делиться или открыть источник | Предложить доступное действие там, где оно разрешено и доступно. | 0033 |
| Доступ отозван во время preview | Не раскрывать ограниченные source details ни визуально, ни через assistive representation; сохранить безопасный путь восстановления. | 0036, 0050 |

VoiceOver, Voice Control, Switch Control, Full Keyboard Access, Dynamic Type,
Reduce Motion, Reduce Transparency и contrast требуют проверок на выбранных
устройствах. Наличие сценариев не доказывает поддержку этих средств. Ещё
открыты target OS, чтение и группировка плотной сетки, приоритет объявлений при
потоке обновлений, ограничения disclosure и фактическая фокусировка при
изменении данных. Системные controls предпочтительны, но конкретный API и
макет здесь не выбраны.
