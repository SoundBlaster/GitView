# GitHub connection: вопросы к проверке источников

Это план проверки допущений кандидатов [0019](GITVIEW-SPEC-0019.yaml),
[0036](GITVIEW-SPEC-0036.yaml), [0058](GITVIEW-SPEC-0058.yaml) и
[0059](GITVIEW-SPEC-0059.yaml), а не утверждение о доступных GitHub API или
iOS. Ответы могут изменить контракты и соответствующие acceptance scenarios.
Запросы и численные лимиты здесь не выбираются.

| Вопрос | Что установить до выбора решения | Влияние на граф |
| --- | --- | --- |
| Authorization для iOS | Поддерживаемые GitHub способы для клиента, границы безопасного обмена, подтверждение source identity и доступные условия отмены. | 0019, 0058: начало и завершение connection, поздние результаты и восстановление. |
| Права и организации | Какие полномочия нужны выбранному read-only набору данных, как на доступ влияют настройки организаций и отдельные repositories. | 0036, 0045, 0059: частичное разрешение и повторная проверка до setup. |
| Discovery | Что именно охватывает перечисление, как распознаются scope, неполная выдача и завершение для выбранного способа. | 0022, 0059: наблюдаемая полнота и подтверждённый пустой результат. |
| Неоднозначный отказ | Какие source-сигналы действительно подтверждают отсутствие или отказ, а какие допускают несколько причин. | 0036, 0038: видимость кэша, сохранение identity и membership. |
| Credential lifecycle | Доступные платформенные гарантии хранения и удаления, восстановление после ошибок, ограничения при прерывании приложения. | 0058: допустимый connection state и evidence удаления локального credential. |
| Смена подключения во время setup | Как связать фактические асинхронные операции с подтверждённой identity и обработать уже начатую локальную запись. | 0045, 0058, 0059: корректная admission boundary и восстановление результатов. |

Проверка должна различать официальное описание возможностей, принятый для
GitView способ и позднее наблюдение интеграции: документация сама не докажет,
что приложение или его тесты работают. Права и способ authorization не
назначаются до такого сопоставления.
