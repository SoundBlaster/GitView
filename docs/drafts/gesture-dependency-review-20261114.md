# Зависимости жестов и preview

Авторская сверка candidate 0075 и непосредственных родителей на 14 ноября.
Смысл `depends_on` и `refines` описан в [предыдущем review](dependency-semantics-review-20261114.md).
Рассмотрены реальные поля и acceptance-сценарии узлов, но не каждое ребро
всего транзитивного closure. Подсчёт ниже не является оценкой готовности.

| Изменение | Основание |
| --- | --- |
| Удалено 0075 → 0074 | Для проверки конфликтов pinch/scroll/preview не нужен весь контракт переходов портфеля, составных Project-сигналов и исторических outcomes. Сохранены 0035 как родитель, 0024 для context/fallback, 0049 для Today и 0073 для доступного focus. Требование о том, что pinch не меняет scope, остаётся непосредственно в 0075. |
| Удалено 0031 → 0016 | Static preview должен открываться и закрываться без случайного sharing, но реализация и проверка sharing не обязательны для этого контракта. Сохранены требования доступа, идентичности, восстановления и доступных альтернатив. 0016 всё ещё достижим транзитивно через 0017; удаление прямого ребра не означает удаления функции sharing. |
| Сохранены 0075 → 0015 и 0031 | Первый фиксирует пользовательскую границу static preview первой версии и будущего sliding; второй задаёт объект preview и восстановление при dismissal. Это разные обязанности, несмотря на транзитивную достижимость. |
| Сохранены 0075 → 0024, 0032, 0036, 0049, 0073 | Соответственно используются восстановление context, альтернативы жестам, отзыв доступа, смена Today и доступный focus при изменении коллекции. Их необходимость и гранулярность могут быть пересмотрены после дальнейшего refinement; этот проход не доказывает их принятие. |

До исправления от 0075 были достижимы 43 других узла по `depends_on` и 50 по
объединению с `refines`; после — соответственно 35 и 49. Удаление прямого
0031 → 0016 не сократило его dependency closure: эта цель остаётся достижимой
через 0017. [Снимок с идентификаторами и SHA](evidence/autonomous-goal-gesture-dependency-reachability-20261114.json)
позволяет воспроизвести текущий подсчёт. Снижение числа не является целью и
само по себе не доказывает правильность графа.

Проверка candidate структуры и ontology vocabulary не проверяет необходимость
рёбер или поведение нативных жестов. 0075 остаётся `pre_canonical`; пороги,
прерывания платформой и доступность не проверены на iOS.

Следующий шаг — отдельно рассмотреть 0017 как общий контракт доступности:
он одновременно ссылается на функции приложения и должен применяться
сквозным образом. Нельзя предполагать, что наличие общей спецификации уже
доказывает применимость и исполнимую проверку для каждого leaf.
