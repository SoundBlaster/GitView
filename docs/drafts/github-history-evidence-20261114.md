# Исторические метрики: источники и пределы выводов

Документальный срез 14 ноября 2026 года. Наличие API-поля — свидетельство
возможного представления факта, но не доказательство полной истории, доступа
или согласованной выборки для проекта пользователя.

| Метрика | Что может быть основанием | Что ещё нужно доказать |
| --- | --- | --- |
| Merged PR за период | GitHub документирует `mergedAt` у PR и `MergedEvent` с временем. [GraphQL PR](https://docs.github.com/en/graphql/reference/pulls) | Полная выборка подходящих PR во всех Repository, identity, права, границы периода и покрытие. |
| Закрытия Issue по причинам | GitHub документирует `ClosedEvent` с nullable `stateReason` и временем; также есть события повторного открытия. [GraphQL Issues](https://docs.github.com/en/graphql/reference/issues) | Доступность причины для конкретного события, полнота истории и корректная единица: события или разные Issue. |
| Открытые PR / Issue в прошлом | Подходящий сохранённый snapshot или отдельно обоснованное восстановление из baseline и всех нужных переходов. | Полнота населения, событий, времени и access для каждого Repository; текущее состояние не доказывает прошлое. |
| CI / review / threads / blockers в прошлом | Контекстные сохранённые observations либо отдельно доказуемое восстановление соответствующего predicate. | История отдельных сигналов, revision, связей, coverage и retention; одно событие закрытия Issue их не восстанавливает. |
| Состав GitView Project в прошлом | Локально сохранённая история membership с достаточными identity и временем. | Её наличие и политика retention в GitView ещё не определены; GitHub Project и organization не являются этим локальным Project. |

GitHub документирует [REST timeline events](https://docs.github.com/en/rest/issues/timeline)
для Issue и PR, но сама документация операции не устанавливает полноту для
любого выбранного периода и набора объектов. По [документации GitHub](https://docs.github.com/en/rest/guides/using-the-rest-api-to-interact-with-checks)
retention checks зависит от настроек; нельзя предполагать бессрочную историю.

Эти выводы относятся к candidates [0030](GITVIEW-SPEC-0030.yaml),
[0064](GITVIEW-SPEC-0064.yaml) и [0065](GITVIEW-SPEC-0065.yaml). Ни одно
реальное обращение к данным пользователя не выполнялось; выбор запросов,
хранения и расписания отложен.
