# Сверка оснований исторического обзора

Авторский обзор черновиков после `1105e0a`; проверены перечисленные контракты,
не весь граф и не выполнение приложения. Он различает факт, который можно
подтвердить, и полноту области, за которую предлагается итог.

| Утверждение | Необходимое основание | Где описано |
| --- | --- | --- |
| Одна Issue закрылась в выбранный период | Идентичность и тип Issue, поддержанное событие и его время, применимый доступ. Позднее обнаружение события не меняет его времени. | [0065](GITVIEW-SPEC-0065.yaml), [0056](GITVIEW-SPEC-0056.yaml) |
| Полный итог закрытых Issue за период | Кроме известных событий, достаточный охват исходной совокупности, области, доступа и времени; повторные события одной Issue не создают дополнительные Issue. | [0065](GITVIEW-SPEC-0065.yaml), [0069](GITVIEW-SPEC-0069.yaml) |
| Значение открытых PR в прошлый день | Подходящее сохранённое наблюдение либо отдельно обоснованная реконструкция всех необходимых переходов. Текущий счётчик сам не заполняет пробел. | [0065](GITVIEW-SPEC-0065.yaml), [0069](GITVIEW-SPEC-0069.yaml) |
| Project в прошлой точке | Указанная основа состава и собственный охват каждого Repository; нынешние участники не доказывают прошлое членство. | [0064](GITVIEW-SPEC-0064.yaml), [0056](GITVIEW-SPEC-0056.yaml) |
| Переход от точки к объектам | Поддержанный предикат, период, область и идентичности объектов. Одинаковые числа в точке и последующей выборке не устанавливают одинаковый состав. | [0056](GITVIEW-SPEC-0056.yaml), [0092](GITVIEW-SPEC-0092.yaml) |

Фиксированный набор PR [0055](GITVIEW-SPEC-0055.yaml) и очистка истории
[0067](GITVIEW-SPEC-0067.yaml) — условные предложения: их взаимодействие
описано там, где они выбраны, но они не являются предпосылками обычного Today
или исторической выборки. [0097](GITVIEW-SPEC-0097.yaml) уточняет последующее
представление дополнительных рядов и зависит от соответствующих родительских
контрактов; обратное ребро из родителя без проверки породило бы цикл.

Текущий исходный вариант запросов и схемы не доказывает полных GitHub
permissions, сохранения истории или неизменности данных при пагинации. Поэтому
наличие нескольких подтверждённых событий поддерживает их показ с ограничением,
но не гарантирует точный итог или полный график. Проверка ссылок и структуры
не заменяет будущую проверку source mappings, хранения и native presentation.
