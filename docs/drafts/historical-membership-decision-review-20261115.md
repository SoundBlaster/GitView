# Исторический график и состав Project

На вопрос о добавленном сегодня Repository владелец ответил:
«Пересчитывать по нынешнему составу Project». Вопрос и точный ответ связаны
в SpecDraft revision `a55f271ca16f4283bfaf67095616ee7a`. Решение относится
к историческим графикам Project; оно само по себе не выбирает правила всех
исторических счётчиков или способ определения прошлой membership.

На базе `5bae442` обновлены узлы 0001, 0013 и 0047 и подготовлен сквозной
узел 0020. График пересчитывается по текущему составу за выбранный период;
добавление может включить подтверждённую прошлую активность Repository,
удаление исключает его из последующего пересчёта. Это не доказывает его
членство в Project в прошлом и не превращает недоступную историю в ноль.

не подтверждают историю GitHub, работу графика или готовность реализации.
