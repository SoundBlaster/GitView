# Issue: закрытие, повторное открытие и граница дня

Сквозная сверка 0027/0049/0056/0069/0089 и сценариев 0043. Она сохраняет
три разных вопроса: входит ли объект в динамический Today, было ли закрытие
в выбранном прошлом периоде и соответствует ли текущее состояние активному
фильтру. Входы каждого вопроса требуют собственного evidence.

| Ситуация | Today | Историческая выборка closure | Current-closed filter |
| --- | --- | --- | --- |
| Закрыта до полуночи, после полуночи подтверждённо снова open | Входит как незавершённая. | При подтверждённом времени входит за предыдущий день один раз. | Исключает объект из фильтрованного представления; событие не удаляется. |
| Текущее open известно, но время прежнего закрытия и полнота истории неизвестны | Входит как open. | Совпадение с конкретным прошлым днём unknown, не подтверждённый ноль. | Результат зависит от отдельно установленного текущего состояния. |
| Та же Issue закрылась в два разных дня | Определяется актуальным состоянием и сегодняшними событиями. | Каждый дневной bucket может содержать её один раз; общий distinct-Issue total — один, event count — два. | Не меняет историю. |

[Модель примера](evidence/issue-reopening-day-boundary-model.py) использует
одну вымышленную Issue и явно заданные подтверждённые события до и после
локальной полуночи в New York. Выбранный день перехода с летнего времени
длится 25 часов; расчёт использует полуоткрытые интервалы и host time-zone
database. Текущее состояние передаётся отдельно, не восстанавливается из
одного события. [Выход](evidence/autonomous-goal-issue-reopening-boundary-20261114.json)
содержит входные моменты и hashes связанных спецификаций.

Это один контролируемый пример, а не полная проверка всех зон, source event
ordering, history coverage, privacy, iOS Calendar или приложения. При
неполном source evidence модель ожидает unknown; она не доказывает, что GitHub
предоставляет требуемую историю. Старый [calendar-history model](evidence/calendar-history-model.py)
повторён после изменения 0069, но также остаётся host-side design evidence.
