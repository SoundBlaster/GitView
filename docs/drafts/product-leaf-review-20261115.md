# Сверка пользовательских ветвей первого прохода

Авторская проверка по критерию [0127](GITVIEW-SPEC-0127.yaml): понятны ли
сценарий, последствия и оставшиеся продуктовые вопросы, без требования
заранее выбрать реализацию. Это не исполнение сценариев и не утверждение
всех технических contracts. Структурный лист определяется по отсутствию
детей `refines`, а не по готовности к разработке.

| Маршрут и узел | Сверка с продуктовой проекцией | Что остаётся открытым |
| --- | --- | --- |
| Первый запуск [0022](GITVIEW-SPEC-0022.yaml) | Подключение, выбор Repository, отмена, неполный поиск и проблема чтения сохранённых Projects различены; сохранён сценарий одного Project на Repository. | Подтверждение выбора и сохранение default association — варианты агента; конкретный способ подключения и восстановление не утверждены. 0022 не является структурным листом, включён для связности маршрута. |
| Состояние обзора [0023](GITVIEW-SPEC-0023.yaml) | Нет Projects, данные ещё не получены и частичная ошибка представлены разными случаями; допускаются последние разрешённые данные с их временем и ограничениями. | Компромисс offline и приватности после потерянного отзыва ещё не выбран; автоматическое обнаружение любого отката не обещается. |
| Возврат [0024](GITVIEW-SPEC-0024.yaml) | Project, фильтры и масштаб сохраняются, когда они ещё применимы; пропавший объект не подменяется другим, ограничение доступа важнее сохранения позиции. | Cold-launch overview — предложение агента; восстановление после удаления Project и системные lifecycle-сценарии требуют последующего UX и platform review. |
| Жесты [0075](GITVIEW-SPEC-0075.yaml) | Прокрутка, pinch внутри обзора и статический long-press preview имеют различимый смысл; прерванный жест не равен открытию объекта. | Точная плотность, анимация и доступность native gestures проверяются позже; cross-scope pinch не выбран. |
| Preview [0093](GITVIEW-SPEC-0093.yaml) | Сохраняются identity и доступ выбранного объекта, возможен показ последнего допустимого содержимого; плотная ячейка не обязана вмещать все поля. | Состав и порядок preview — предложение агента, native layout и своевременность отдельных полей не проверены; sliding preview — отдельное будущее направление. |

Рассмотренные узлы связаны с основным маршрутом в
[продуктовой проекции](product-first-pass-20261115.md). Проверка ограничена
этими пятью узлами и их перечисленными последствиями; она не доказывает
семантическую полноту остальных листьев или пригодность маршрута к реализации.
