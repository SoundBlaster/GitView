# GitView: результаты обмена наблюдениями

[0123](GITVIEW-SPEC-0123.yaml) уточняет, какие identity, время, scope,
значение и evidence должны восстанавливаться вместе для каждого факта и
aggregate. Он отличает поддержанную пустоту от пропущенного запроса и отдельно
сохраняет контекст coverage и границу history clear. Это логический контракт,
а не физическая схема или результат проверки SQLite.

Рабочая таблица к [0116](GITVIEW-SPEC-0116.yaml): состояние одного поля,
состояние source attempt, coverage, локальная запись и право показа — разные
оси. Таблица описывает продуктовый контракт, не фактические Swift-типы,
database schema или поведение реализованного адаптера.

| Новое свидетельство | Предыдущее значение | Что получает маршрут при разрешённом показе |
| --- | --- | --- |
| Подтверждённое значение T2 и достаточное сравнение с T1 | Доступное T1 | T2 со своим контекстом; другие поля не получают T2 автоматически. |
| Подтверждённая semantic absence или empty для той же области в T2 | Доступное T1, надёжно более старое | Известное отсутствие или empty в T2; историческое T1 не объявляется никогда не существовавшим. |
| Поле не запрошено или его результат с ошибкой | Независимо читаемое разрешённое T1 | T1 остаётся last known со своим временем и применимым ограничением; ошибка T2 отдельно относится к попытке. |
| Поле не запрошено или его результат с ошибкой | Нет надёжно восстановленного значения | Unknown или unavailable; не zero, не empty и не текущий успех. |
| Два несовместимых значения без достаточного порядка | Есть или нет прежний baseline | Conflict или uncertainty; last known может быть показан только с собственным контекстом и ограничением. |
| Любое значение | Доступ стал явно ограниченным | Закрытые значения и раскрывающие counts не показываются; безопасный общий статус допустим при соответствующей политике. |

| Источник и storage | Что можно утверждать |
| --- | --- |
| Source дал допустимые факты, локальное сохранение не подтверждено | В текущей сессии допустим transient показ с контекстом; durable результат не заявляется. |
| Локальная запись подтверждена для операции | Известен исторический исход этой операции; отдельное текущее чтение ещё может быть недоступно. |
| Запись завершилась ошибкой, а читать предыдущее состояние нельзя | Ни старое, ни новое значение не объявляется восстановленным без независимого свидетельства. |
| Scope частичный, все полученные факты сохранены | Сохранённый набор остаётся частичным; это не полная population и не пустой неохваченный Repository. |

Текущий результат может содержать несколько строк таблицы одновременно.
Например, title T2 доступен, review T1 остаётся last known, CI недоступен,
source request завершился частично, запись неопределённа, а Project coverage
неполон. Нельзя свести всё это к одному `success` или одному времени обновления.
