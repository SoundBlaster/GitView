Сценарий в 0032 связывает изменение масштаба, альтернативный вызов preview и dismiss для Issue с неоднозначным номером. Он текстовый: автоматизированный тест или проверка VoiceOver, Switch Control и других способов ввода не выполнялись. Конкретные system APIs, порядок обхода и platform feasibility остаются открытыми; прямое открытие объекта не заменяет доступ к preview.
