# Today evidence to historical charts

Status: agent-authored illustrative extension of the [Today example](today-source-union-worked-example-20261115.md), not an executed product test or a claim of GitHub history coverage. The Project P membership basis is captured as A and B. Its required source permissions and completeness remain unproven.

Assume the facts in that example were independently accepted during a source
attempt at T inside the same local day, after the stated creation and merge,
are permitted under current disclosure, and each applicable
retention operation has its own established or unresolved outcome. A supported
source fact does not imply that its local write succeeded.

| Proposed history material | Admission and later presentation |
| --- | --- |
| Open PR state at T | The known applicable X contribution supports an observed subset of one PR if its required evidence is retained. It is not an exact P value or an automatic lower bound at a later time. Z is merged and does not add to the open-state subset. |
| Closed-Issue outcome for elapsed `[D0, T)` | Y's creation and current closed state do not establish a closure event in the interval. With no separately supported event or sufficient complete event coverage, this bucket is unavailable or incomplete, never a zero or an inferred event. |
| Merged-PR outcome for elapsed `[D0, T)` | Z's supported merge at D0 can contribute one distinct PR to a partial outcome for that period if the required event and identity evidence are retained. It is not a complete P bucket without compatible coverage of A and B or a full-day result. |
| Today lifecycle breakdown at T | A retained point needs the selection predicate, captured day, member basis, current lifecycle evidence and actual coverage. X, Y and Z can be supported contributors; U remains an uncertain selection candidate and is not an invented member of a lifecycle category. A later day needs a separate evaluation. |

When history is opened later, independently recoverable and permitted evidence
can support these limited points with their original meaning and times. Opening
the chart, recomputing the same cache or replaying the same local operation does
not create a fresh observation at that later time. An indeterminate save receipt
alone does not prove that a point survived restart; a confirmed terminal failure
does not prove that an older point survived either. A separately confirmed new
source observation may support a new sample even if the value is unchanged.

If P subsequently changes from A+B to A+C, the old A+B material retains its
captured basis. Recomputing A+C requires separately applicable permitted
evidence for C and compatible A evidence. The old total cannot be converted by
subtracting an unknown contribution of B. A graph must not connect the two
bases as an uninterrupted same-scope trend. Restricted values and revealing
comparisons are withheld under 0064; absence of current access does not prove
that an earlier event never occurred.

The initial state charts place supported observations at their actual sample
times; event outcomes occupy their captured half-open buckets. Missing evidence
is shown as a gap or explicit limitation, with a non-color accessible route;
the graph does not interpolate an observed trend through a missing interval.
Opening an object selection from an aggregate additionally requires separately
supported identities and the original predicate and scope. This example is a
future controlled-test fixture, not evidence of an implemented chart, durable
recovery, current GitHub grant or a complete historical series.
