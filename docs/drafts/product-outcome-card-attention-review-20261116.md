# PR, Issue и сигналы внимания: проверка пользовательской пользы

Ограниченная авторская сверка карточек и связанных сигналов по пользовательской цели: быстро узнать работу, увидеть состояние и проблемы и перейти к нужному объекту. Это не утверждение всего графа, не проверка API GitHub и не свидетельство работающего интерфейса.

| Узлы | Пользовательская задача и результат сверки |
| --- | --- |
| 0008, 0041 | Узнать PR, его Repository, состояние и выбранные счётчики изменений, CI и review; открыть источник. Сохранены отдельные сигналы и выбранные поля без обязательного diff, commit или run browser. |
| 0009, 0039 | Узнать Issue, состояние, автора и исполнителей, связанные PR и другие Issue, увидеть выбранные счётчики и открыть источник. Связь не доказывает мотив; закрытие само по себе не равно успешному выполнению. |
| 0031, 0050 | Long press первой версии позволяет посмотреть дополнительные доступные детали того же объекта без ухода с обзора. Compact preview может показывать часть полей, полный выбранный overview доступен отдельно; индивидуальное содержимое тредов и checks не требуется. |
| 0011, 0028, 0062 | Понять CI и review через выбранные счётчики и независимые сигналы. Неизвестное не становится успехом; число тредов не равно числу PR. Реальная GitHub mapping и статус готовности к merge остаются открыты. |
| 0063 | Заметить заблокированную Issue и перейти к затронутой работе, сохранив различие между blocker и заблокированной Issue. Выбранная пользователем категория сохранена; точный source mapping и прямой predicate требуют уточнения. |
| 0125 | Видеть подтверждённые завершения и нуждающееся в review, не называя автоматически условное сочетание CI и review готовностью к merge. Смысл объединённого ready остаётся открытым. |
| 0094 | Заметить проблемное или долго ожидающее ответа обсуждение. Убран преждевременный перечень гипотетических измерений и частных сценариев; пользовательская потребность, смысл сигнала, порог и источник остаются явно открыты. |

В согласованном private revocation сохранённые локальные сведения остаются видимыми как last known с индикацией и поддержанным временем, синхронизация останавливается, доступны recovery или явное локальное удаление под 0019. Эта сверка не выбирает disclosure при смене аккаунта и не устанавливает native presentation.
