# Проверка ветвей Issue и PR при частичных полях

Авторская сверка [0039](GITVIEW-SPEC-0039.yaml),
[0041](GITVIEW-SPEC-0041.yaml), [0050](GITVIEW-SPEC-0050.yaml) и общей
политики [0044](GITVIEW-SPEC-0044.yaml). Готовность к реализации не
установлена; таблица описывает ожидаемые результаты, не выполненные tests.

| Доступные данные | Что можно показать | Что остаётся неизвестным |
| --- | --- | --- |
| Новый title PR, старые review и checks | Title с новым context; старые разрешённые данные со своим временем либо unavailable. | Что review/checks обновились вместе с title. |
| Известен commit count, additions/deletions отсутствуют | Известный commit count. | Изменённые строки; они не становятся нулём. |
| У Issue известен closed state, reason недоступен | Состояние closed. | Выполнена ли работа успешно и причина закрытия. |
| Получены два direct sub-issues, полнота списка не доказана | Наблюдённая часть с ограничением coverage. | Полное число непосредственных sub-issues или процент завершения работы. |
| Обновлён title Issue, links не получены | Новый title и прежние разрешённые links с их context либо unavailable. | Что список links пуст или обновлён вместе с title. |

Для implementation readiness остаются source semantics каждого поля,
сопоставление revision, UI и доступность mixed freshness, обработка доступа и
проверяемое отображение partial collections. Никаких предположений о том, что
конкретный GitHub response предоставляет эти гарантии, здесь не сделано.
