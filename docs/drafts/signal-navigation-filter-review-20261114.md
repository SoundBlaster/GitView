# Сигнал, выборка и изменение фильтра

Сверка 0012/0029/0046/0047/0057 с навигацией 0024/0074/0091 и исторической
выборкой 0056. Она фиксирует продуктовые предложения, а не native test.

| Действие или изменение | Что сохраняется | Чего нельзя заключить |
| --- | --- | --- |
| Открыть пять failed checks в двух PR | Исходное условие и единица checks; в destination два PR. | Что пять означает пять карточек или три потерялись. |
| Явно убрать failed-CI filter | Фактические оставшиеся фильтры, Project и происхождение перехода. | Что все показанные теперь PR по-прежнему failed. |
| Обновить источник после первоначального count | Свой контекст T1 у origin и T2 у новых данных. | Что различие чисел само по себе ошибка или источник изменён приложением. |
| Открыть сигнал после изменения состава Project | Его условие и допустимый исходный контекст; текущая область следует сохранённому составу. | Что старый полный count применим к новому неполному составу. |
| Открыть прошлые closure для вновь открытой Issue | Исторический период и event predicate; отдельное текущее состояние. | Что событие равно фильтру currently closed или динамическому Today. |
| Явно убрать исторический event predicate | Допустимое происхождение перехода и фактически оставшиеся условия. | Что новая выборка всё ещё является исходным набором closure events. |
| Получить denial до показа destination | Допустимый общий статус и доступный route. | Право раскрыть старый private count или объект ради сохранения соответствия. |

Кандидат 0092 предлагает трактовать condition сигнала как идентифицируемый
начальный фильтр, который можно явно изменить. Происхождение перехода и
активные фильтры — разные части контекста; если условие удалено, заголовок
и содержимое не должны обещать прежний predicate. Возврат следует реальному
маршруту, без создания промежуточных экранов.

Пока не выбраны конкретные native controls, отображение нескольких времён,
поведение после полного закрытия route и source mapping. Эта сверка не
устанавливает, что компонент существует, count исчерпывающий или доступ
к private данным подтверждён.
