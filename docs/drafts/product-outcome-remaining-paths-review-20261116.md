## 3. Навигация и доступность

Прочитаны 0006, 0007, 0014, 0015, 0017, 0024, 0032, 0035, 0073, 0074, 0075 и 0093. Маршрут Project → работа → статический preview → объект сохраняет выбранный контекст. Single-Repository Project не требует дублирующего промежуточного экрана; сигнал ведёт к соответствующей работе. Обычный default entry для multi-Repository Project остаётся кандидатным.

Today включает старую незавершённую работу и результаты текущего локального дня; без выбранного исключения видны открытые и завершённые объекты, по одной ячейке на объект. Фильтры сохраняются, а выбранный переход из исторического merged counter временно обходит конфликтующий фильтр без перезаписи настройки. Pinch меняет плотность, не scope; first-version long press даёт статический preview, sliding preview остаётся будущим направлением. Essential actions доступны альтернативами без обязательного pinch, long press, цвета или точной маленькой цели. Это текстовая сверка, не испытание VoiceOver или устройства.
