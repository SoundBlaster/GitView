Network double **не требуется** для чистого вычисления 0110: оно не выполняет
сетевой эффект; для route и adapter он применим. Gesture/device check **не
применяется непосредственно к pure decision**, поскольку у неё нет UI; он
остаётся обязательным для соответствующего пользовательского пути. Проверка
внешнего процесса обязательных PR/Issue descriptions не является тестом этого
route: чтение выбранного source body при открытии overview имеет собственные
product и accessibility обязательства.

До заявления implementation readiness необходимо определить source mappings и
coverage для входов Today, конкретные границы и recovery хранения, разрешённые
версии зависимостей, состав и ownership FSD, а также native navigation и
accessibility contracts. Наличие маршрута, SHA или статуса `checked` не решает
эти вопросы. Сохранённый snapshot фиксирует версии для повторной оценки: после
изменения предпосылки соответствующие выводы нужно пересмотреть.
