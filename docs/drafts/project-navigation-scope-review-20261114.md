# Переходы Project и изменение состава

Сверка 0004/0005/0006 → 0023/0024/0074 и нового 0091. Основание — Project
с одним или несколькими Repository, возможность общего Repository и прямой
вход в содержимое Project с одним участником. Этот разбор — предложение агента,
не подтверждённое native взаимодействие.

| Исходный выбор | Изменение состава | Результат |
| --- | --- | --- |
| Вход в однорепозиторный Project напрямую | Добавлен второй Repository | Область остаётся Project-wide и включает новый состав; прежняя полнота для одного Repository не переносится на два. |
| Явно выбран Repository A в Project | Добавлен B | Выборка остаётся A-specific, пока пользователь сам не изменит scope. |
| Project-wide A+B, выбран signal | B заменён на ненаблюдавшийся C | Условие signal сохраняется; актуальная выборка A+C неполна и старый сигнал A+B не становится полным результатом A+C. |
| Открыта работа B внутри Project | B удалён из этого Project | Нельзя подменить B на A или автоматически выбрать другой Project; показать изменение origin и доступный путь. |
| Preview открыт через однорепозиторный Project | Project расширился | Preview не меняет объект; возврат следует исходному маршруту и не создаёт задним числом промежуточный экран. |
| Из состава A+B открыта работа A через обзор участников | B удалён, A и Project остаются доступны | Можно восстановить реальный origin в текущей сессии; последующий новый вход использует прямой маршрут одного участника. |
| Исход сохранения состава неизвестен | Конфигурация недоступна | Нельзя утверждать ни старый, ни предложенный набор как подтверждённый; scope и его aggregate остаются uncertain. |

В 0074 одно-Repository shortcut теперь явно несёт Project-wide intent.
Это не означает, что gesture изменяет scope, и не отменяет отдельно выбранный
Repository scope. Данные, permissions и состояние preview остаются независимы
от локального membership; чужой Project не восстанавливает доступ сам по себе.

Открыты native UX, фокус и доступность при перестройке, семантика источника и
атомарность сохранения состава. Ни один сценарий не выполнялся в приложении;
сверка и проверка словаря не доказывают их платформенную реализуемость.
