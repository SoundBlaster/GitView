# GitView UX prototypes

Сохранённые интерактивные черновики из беседы. Начальная страница:
[index.html](index.html). Каждый пример содержит отдельные редактируемые
`index.html`, `styles.css`, `app.js`. Это UX-прототипы, не реализация iOS-приложения
и не canonical specifications. Все данные вымышлены; обращения к GitHub нет.

- [Peek and Pop](peek-pop/index.html): крупная сетка, preview и объект.
- [Плотный обзор](dense-overview/index.html): 100 клеток, 2–10 колонок,
  long press со скольжением, hover, pinch и возврат к прежнему месту.

## Открытие

Начальная страница — `index.html`. Проверенный способ открытия — локальный
HTTP-просмотр из корня GitView:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory prototypes
```

Затем откройте `http://127.0.0.1:8000/`. Сборка и установка зависимостей не нужны.
Прямой `file://` заблокирован используемой browser automation и этим прогоном
не проверен. Все страницы и зависимости проверены через localhost с блокировкой
внешних запросов: работа не требует сервиса беседы или сети за пределами localhost.
Стили, код и библиотека значков лежат локально. Файлы можно переносить вместе
со всей папкой `prototypes/`. Предпочтение светлой/тёмной темы берётся у браузера.
Локальное сохранение UI-состояния зависит от доступности browser localStorage;
при его ограничении взаимодействия работают с состоянием в памяти.

## Структура и редактирование

- `index.html` каждого примера — разметка и подключения ресурсов.
- `styles.css` — стили изображённого приложения.
- `app.js` — демонстрационные данные и взаимодействия.
- `shared/prototype.css` — оформление окружающего предпросмотра и его контролов.
- `shared/state.js` — локальная замена state API беседы; соединения с чатом нет.
- `shared/vendor/` — закреплённая библиотека Lucide с исходной лицензией.
- `export-manifest.json` — происхождение, версии и SHA-256 экспортированных
  исходников и сохранённых файлов. Hash фиксирует момент экспорта; после ручной
  доработки файла он закономерно перестанет совпадать с этим снимком.

Изменения локальных HTML/CSS/JS не синхронизируются автоматически с визуализацией
в беседе. При следующем показе используйте явно выбранную версию, чтобы не
выдать старый пример за новую редакцию.

Экспорт выполнен штатным renderer visualize 1.0.66, затем авторские разметка,
CSS и JS разделены для независимого редактирования. Экспортные промежуточные
оболочки не нужны для открытия этих папок. Host-only design controls (`Tweak`)
не включены в локальные страницы; основные взаимодействия доступны напрямую.
Lucide используется в HTML-макетах; это не доказательство интеграции SF Symbols
или Liquid Glass на iOS.

Проверены preview → объект → возврат, локальные значки, сохранение плотности
после reload, 100 клеток и long press → скольжение между ними. Эти проверки
относятся к локальным HTML-прототипам, не к физическому iPhone.
