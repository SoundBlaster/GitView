# GitView ontology draft.8 — кандидат уточнения Metric

Кандидат на основе рабочего draft.7: изменены версия пакета и только описание
`Metric`. Значение может быть количественным или временным; определение,
серия и визуализация не приравниваются к одному результату. Отсутствие и
неизвестность не объявляются измеренным нулём. Новый class, actor/action,
конкретная схема хранения и source adapter не добавляются.

[Аудит 18 прямых потребителей](../../review/metric-consumer-audit.md) описывает
обоснование, границы и непринятые решения. Компилятор с локального snapshot
SHA-256 `30dd324aa1f641e7274a49fd6f158cced5ed95d810b6b275353d3d10f19a27cb`
прошёл `check` без diagnostics и `compile`; compiler provenance независимо
не подтверждён. После [сравнения 84 candidate specs](verification.json) пакет
выбран рабочим черновым контекстом. Количество findings и gaps совпало с
draft.7, включая прежний warning в 0001. Semantic approval не установлен;
структурная проверка не подтверждает интерпретацию или поведение приложения.
После изменения путей к контексту повторно проверены четыре затронутые specs:
0001 сохранил прежний warning/gap, в остальных findings и gaps отсутствуют.
`ontology-doctor` подтвердил выбранную композицию; compiler provenance и
semantic approval остаются неподтверждёнными.
