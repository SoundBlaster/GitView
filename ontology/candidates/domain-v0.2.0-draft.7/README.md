# GitView ontology draft.7 — кандидат уточнения CIStatus

Кандидат, не canonical ontology. Основан на выбранном draft.6: изменены версия
package и только описание `CIStatus`. Предлагается значение
source-reported состояния одной status-check entry; агрегаты остаются
производными измерениями, а сведения об источнике и scope — необходимым
контекстом. Не добавлены ни entity проверки, ни актор, ни отношение.
Отсутствие значения не равно успеху или известному нулю.

[Сверка шести прямых потребителей](../../review/ci-status-consumer-audit.md)
объясняет обоснование и границы. Рабочая selection для подготовки графа
переключена на draft.7; это не утверждает семантику и не подтверждает source mapping.
Локально собранный compiler `ontologyc` SHA-256
`30dd324aa1f641e7274a49fd6f158cced5ed95d810b6b275353d3d10f19a27cb`
прошёл `check` без diagnostics и `compile`; его происхождение независимо
не проверено. [Сравнение](verification.json) охватывает 84 одинаковых входа
draft.6 и draft.7: число findings и gaps совпадает, в 0001 остаётся один
warning о метке продукта. `checked` не равен semantic approval. Перед
сравнением изменившиеся 0043, 0061 и новый 0084 повторно проверены на draft.6.
После переключения четыре specs, ссылающиеся на путь контекста, повторно
проверены на конечных байтах: 0001 сохранил прежний warning/gap, остальные
не имеют findings и gaps. `ontology-doctor` подтвердил выбранный контекст;
semantic approval остаётся `not_established`.
