## Рабочая формулировка Project

Для содержательной проверки предлагается: **Project — локально определяемая
единица организации обзора работы в GitView**. Это предложение о назначении
понятия, не новое решение владельца и не изменение draft.12.

Отдельно от этой формулировки: Project имеет собственную identity, имя и
возможное описание; его состав связывает его с одним или несколькими
Repository. Один Repository может входить в разные Projects, а GitHub
organization не определяет Project. Так различаются определение, свойства и
отношения, как просил владелец. Два отдельно созданных Projects могут иметь
одинаковые названия и состав, но оставаться разными, если их отдельные identity
подтверждены; совпадение названия или состава само по себе их не объединяет.

Формулировка ограничена GitView и не объявляет общую сущность Project для
других продуктов. Её полезность для словаря ещё требует содержательной оценки;
структурная проверка пакета не определяет правильность такого значения.
